# Inventor2023AIAssistant
AI-powered chat assistant add-in for Autodesk Inventor 2023

## Created by
Blake Conner — HVAC Manufacturing and Technology, Inc. — Athens, TX

## What It Does
Embeds an AI chat panel inside Autodesk Inventor 2023 powered by
Groq (llama-3.1-70b-versatile). Supports geometry analysis, drawing
automation, HVAC engineering calculations, and more.

## Built With
- C# .NET (Visual Studio 2019)
- Autodesk Inventor 2023 COM API
- Groq AI API (llama-3.1-70b-versatile)
